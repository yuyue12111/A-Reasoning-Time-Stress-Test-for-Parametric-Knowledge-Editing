\section*{Contents}
This supplement discharges the six places where the main text defers material,
and carries the tables the reproducibility checklist points at.  Nothing here
introduces a quantity that is not already recorded in the frozen results file;
sections that would require a new computation say so and stop.

% ---------------------------------------------------------------- S2b
\section{Judge-Panel Missingness Pattern}
% Discharges: "bound; the missingness pattern is reported in the supplement."
The validation panel returned votes for 87 of 120 stratified items.  This section
reports \emph{how} the 33 absences are distributed across the rule-positive and
rule-negative strata, and the rate-limit mechanism that produced them.  It does
not report a sensitivity analysis: re-scoring under alternative missingness
assumptions would be a new computation, which the pre-submission freeze forbids.

% ---------------------------------------------------------------- S2c
\section{Route-Panel Vote Composition}
% Discharges: "the vote-split composition is in the supplement."
Per-instance route votes are not recorded, so this section reports the aggregate
only: how many of the 41 gated instances were unanimous, how many split
two-to-one, how many split three ways, and the raw pairwise agreement behind the
reported Fleiss' \(\kappa\).

% ---------------------------------------------------------------- S3b
\section{Sunk Section-3 Regressions}
% Supports: reproducibility-checklist regression items.  W4/C3 removed the body
% sentence that referenced these two sunk regressions, so this section no longer
% discharges a body promise; the regressions themselves remain reportable here.
The unedited-base recall control regression, with its coefficient and interval, and
the case-block fits in matched and controlled form with their case-block intervals.
Both are supporting outcomes on the Section 3 source pool and checkpoints, not a
second independent trend line, and neither is re-estimated here.

% ---------------------------------------------------------------- S7
\section{Cloze Installation-Sanity Artifact}
% Supports: the Section 4 statement that the per-item record exists but was never crosswalked.
The per-item logit-lens file is on disk; what does not exist is a crosswalk
between its case identifiers and the answer-only membership sample, so sample
overlap between the cloze reversions and the census population is unknown.  This
section states that precisely, and does not build the crosswalk: doing so would
be a new analysis, which the pre-submission freeze forbids.

% ---------------------------------------------------------------- S1b
\section{Replay-Gate Table}
% Discharges: "route through replay; the complete replay-gate table is in the supplement."
The full X1 gate table, including the officially recorded 9/18 FAIL, the
pre-specified requirement of 15, both prerequisite rates, and the stop rule.

% ---------------------------------------------------------------- S9
\section{Concept-Direction Endpoint Set}
% Discharges: "excluding zero; the complete endpoint set is in the supplement."
All three arms of the concept-direction experiment and every contrast computed on
them, each with its interval and its unadjusted bootstrap p, including the
confirmatory arms whose primary RR contrast was compatible with zero and the
co-primary LocAcc harm contrast reported in the body.

% ---------------------------------------------------------------- S11
\section{Hyperparameters and Run Counts}
% Supports: checklist items 4.2 (partial), 4.10, 4.13.
Per-checkpoint edit layer with how it was fixed --- empirically scanned on two
checkpoints, set a priori by a fixed relative-depth rule on the others, with
every conditional fallback sweep left unfired --- suppression penalty, decoding
settings, seeds, and per-cell run counts.

% ---------------------------------------------------------------- provenance
\section{Provenance and Reproducibility Notes}
% Discharges: "so it carries nothing here.  The released provenance record gives both derivations."
The placebo arm's two derivations in full, the checks that ruled out a benign
explanation, and every other respect in which a re-run of the released code will
or will not reproduce the reported table.
